# ISRSE 2009 Service Demonstration Information

<div class="wiki-archive-note" markdown="span">Archived from the ESIP wiki page <a href="https://wiki.esipfed.org/ISRSE_2009_Service_Demonstration_Information">ISRSE 2009 Service Demonstration Information</a>.</div>

Please provide information about your services that you would like to be
included in our demonstration at the 2009 ISRSE meeting in Stresa.
Please provide all information by **March 20, 2009** to allow us enough
time to integrate the service links and capabilities into the virtual
machine that will be developed and distributed as part of the
demonstration.

Please include the following information for each service you want to
provide:

- A short name for the service
- A narrative description of the service that describes:
  - The purpose of the service
  - The data available through the service
  - Any other related information about the service
- The organization hosting the service (as it should be listed with the
  service links in the VM)
- Organization web site
- Contact name and information for more information about the service
- Type of Service (e.g. REST, SOAP, WMS, WFS, WCS, RSS)
- The service metadata link (i.e. WxS GetCapabilities request, WSDL, API
  documentation)
- Screenshots (optional)
