# Technical Workshop Best Practices

<div class="wiki-archive-note" markdown="span">Archived from the ESIP wiki page <a href="https://wiki.esipfed.org/Technical_Workshop_Best_Practices">Technical Workshop Best Practices</a>.</div>

## The Visioneers are responding to comments on the technical workshops with a short list of recommended practices.

1.  Workshop description should be centered on an educational objective
    ("After the session, participants will be able to ...")
2.  Hands-on instruction, support an interactive session; encourage
    laptop use
3.  Actual, specific instructions (not just demo)
4.  Participants... not an audience
5.  Organizer should offer link to software to download before workshop
6.  NOT PPT centric!
